# 隐私说明

## 仓库里没有什么

- 不包含任何训练好的语音模型（.onnx/.pth，动辄数十 MB）
- 不包含录音素材、语料、聊天记录、个人姓名、真实 IP、PIN
- 不包含 App 签名密钥

## 本地数据的边界

所有数据都在你自己的电脑与手机之间通过局域网传输：

| 数据 | 位置 | 说明 |
|---|---|---|
| DSH 会话内容 | 电脑 DSH 数据目录 | 由 DSH 自身管理 |
| 手机上传的文件 | config.json 的 upload_dir | 默认「手机上传」目录 |
| 推送的文件 | 原文件路径 + bridge/inbox 元数据 | 推送不复制文件，只在 inbox 记录路径 |
| 语音模型 | apps/voice/app/src/main/assets/models/ 或手机私有目录 | 仅本地，不上传 |
| 语料录音 | 手机私有目录 + 电脑 upload_dir | 仅本地 |
| 配对凭据 | bridge/bridge-state.json（本机） | 含设备 token，已在 .gitignore 排除 |

## 语音克隆的伦理要求

DSH 语音 / 语料是为「合成自己的声音」设计的。使用时请遵守：

1. 只录制并训练**本人**声音，或已获得明确书面授权的声音
2. 不得用于伪造他人身份、诈骗、冒充、传播虚假信息
3. 公开分享合成音频时，建议注明「AI 合成」
4. 遵守所在地区关于深度合成/个人信息保护的法律法规

## 数据删除

- 手机 App：设置里清理数据或卸载即可删除录音/模型
- 电脑端：删除 upload_dir、bridge/inbox、bridge/bridge-state.json 即可
- 版本发布目录 bridge/app/ 可整目录删除
