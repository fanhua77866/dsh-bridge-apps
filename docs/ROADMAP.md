# Roadmap

## 已完成（v1.x）

- 手机遥控 DSH（WebView + 常驻通知）
- 文件双向传输（下载/上传/推送/预览/解压/分享）
- 离线 TTS（sherpa-onnx + 模型热更新 + 音乐播放器）
- 训练语料采集（逐句录制 + 实时质检 + 一键上传）
- 实时 ASR 逐字校验（DSH 录音）
- App 自更新（version.json + latest.apk）

## 计划中

- [ ] App 内直接编辑采集脚本（不重新打包 APK）
- [ ] 语料质检报告可视化（SNR/语速/一致性图表）
- [ ] TTS 模型 A/B 对比播放（同一句话多模型连播）
- [ ] 桥接器 HTTPS 可选（自签证书）
- [ ] 多用户/多设备管理界面
- [ ] Docker 化桥接器（可选，非手机直连场景）
